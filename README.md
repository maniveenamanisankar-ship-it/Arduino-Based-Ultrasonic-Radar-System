##Arduino-Based Ultrasonic Radar System

Overview

This project is a simple ultrasonic radar system using Arduino Nano. It uses an HC-SR04 ultrasonic sensor mounted on an SG90 servo motor to detect objects and measure their distance at different angles.

Objective

To develop a low-cost radar-style system that can detect nearby objects and determine their distance and position using an Arduino Nano.

Components Required

Arduino Nano

HC-SR04 Ultrasonic Sensor

SG90 Servo Motor

Breadboard

Jumper Wires

USB Cable

Laptop/PC


Working

The SG90 servo rotates the ultrasonic sensor from left to right. The HC-SR04 measures the distance of objects at different angles. The Arduino Nano processes the sensor data and sends the angle and distance information to the laptop for display.

Servo Motor → Ultrasonic Sensor → Arduino Nano → Laptop → Radar Display
